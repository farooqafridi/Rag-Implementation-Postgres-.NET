18. Production architecture improvements
The implementation above is our initial working prototype. Before deploying it for an enterprise DMS, I would address these areas.
Area	Production implementation
Background processing	.NET Worker Service
Document storage	Azure Blob Storage
OCR	Azure Document Intelligence or local OCR
Security	ASP.NET Core Identity + JWT
Authorization	Document-level permissions
Multi-tenancy	TenantId on documents and chunks
Search	Hybrid search (keyword + vector)
Performance	HNSW + batch embedding
Reliability	Retry policies and failed-job handling
Monitoring	Structured logging and processing metrics
Re-indexing	Track embedding model and version
